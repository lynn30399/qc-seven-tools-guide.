# 直方圖

來源：[textbook](../sources/textbook.md) 第 4 章 p.102–106

## 用途
把數據分布範圍分成幾個區間，統計各區間的出現次數，用長條圖表現。可以看出（第 4 章 p.102）：
1. 數據的分布形態
2. 中心位置（集中趨勢）
3. 離散程度（變異性）
4. 數據和規格的關係

## 使用時機（第 4 章 p.102）
1. 掌握分布狀態，與預期的分配比較
2. 調查離散或偏離的原因（例：比較作業者、機器、材料、方法各自的直方圖）
3. 與規格比較，把規格界限標在圖上看不合格品比例，並判斷是變異數還是平均數的問題
4. 調查改善前後的效果

## 與條形圖的差別（第 4 章 p.102）
直方圖的線條為垂直，且寬度代表該類別涵蓋的範圍；條形圖的線條可垂直或水平，寬度沒有意義。

## 做法（12 步，第 4 章 p.103）
確立目的 → 蒐集數據 → 求最大值 L、最小值 S、全距 R = L − S → 決定區間數 → 求區間寬幅 h = R / k → 決定區間界限 → 求區間中心值 → 製作次數表 → 計算次數 → 作圖 → 記入相關資料 → 觀察分析

**區間數 k 有兩種算法（第 4 章 p.103）**：
- k = √n（例：n = 50，√50 = 7.071，取 7）
- 滿足 2^(k−1) ≤ n < 2^k 的 k（n = 50 時 k = 6，為 Wiki 驗算，課本未列出）
兩者結果可能不同，簡報用哪一條要註明。

**第一區間界限**：下側 = S −（測定單位）/ 2；上側 = 下側 + h。令 e = (S + hk) − L，若 e > h/2，下側改為 S −（測定單位）/ 2 − e / 2（第 4 章 p.103）。
例 4-2：最大 4.555、最小 4.510、k = 7，h = 0.007，e = 0.004，第一區間 4.5075～4.5145（第 4 章 p.104）。計算用到測定單位 0.001，課本未明說。

## 常見形狀與可能原因（第 4 章 p.105–106）
| 形狀 | 特徵 | 可能原因 |
|---|---|---|
| 鐘型 | 中央單一高峰、近似對稱 | 數據為（或接近）常態分配 |
| 雙峰 | 中央低谷、兩旁各一高峰 | 混合兩個鐘型分配：兩部機器、兩組操作員、兩個班別、兩種原料、兩條生產線 |
| 高原型 | 各區間次數差不多，無顯著高峰 | 多個鐘型分配混合；可能無標準作業程序，作業員各行其是 |
| 梳狀 | 次數高低起伏不整齊，像梳齒 | 區間寬度不是測定單位的整數倍，或測定者對刻度有偏好 |
| 偏歪型 | 高峰不在中央，一側尾巴長；尾巴向右為右偏、向左為左偏 | 常發生在數據只有單邊規格界限時（例：強度） |
| 截斷型 | 高峰在或靠近分布邊緣 | 把某些數據從鐘型分配中移去（例：100% 全檢剔除不合格品） |
| 離島型 | 出現兩個高度差很多的高峰 | 較低高峰的數據可能來自特別的機器、製程或作業員（製程異常）；旁邊若是截斷型，代表篩選沒把不合格品剔乾淨；也可能是量測誤差或抄寫錯誤 |
| 邊緣突出型 | 平滑分配的邊緣出現突出高峰 | 通常是資料記錄錯誤 |

## 注意

## 補充來源
- ASQ：用圖形顯示數據的分布，圖形能讓人看出表格數字裡不易發現的型態，並了解次數分布（asq-seven p.3）
- dyu 列的 8 種形狀與課本相同，差異如下（dyu §3）：
  - 名稱：dyu 叫「偏斜型」，課本叫「偏歪型」，簡報用課本
  - 梳狀的原因：dyu 寫量測誤差或分組不當；課本寫區間寬度不是測定單位的整數倍，或測定者對刻度有偏好（第 4 章 p.105）。方向相近，簡報用課本的說法
- dyu 步驟：蒐集資料 → 分組 → 繪圖 → 檢查是否合乎常態 → 找異常原因 → 提改善方案 → 改善後確認（dyu §3）
